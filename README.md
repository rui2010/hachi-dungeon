# 八勇者の迷宮（Webアプリ版）

iPhoneのホーム画面から起動でき、機内モードでも遊べるWebアプリ版です。
**費用は0円で、Macも不要です。** iPhoneだけで公開できます。

## 中に入っているファイル（6つ）
- `index.html`：ゲーム本体
- `sw.js`：オフラインで遊ぶための仕組み
- `manifest.webmanifest`：ホーム画面用の設定
- `icon-192.png` / `icon-512.png` / `apple-touch-icon.png`：アイコン

（この `README.md` はアップロードしてもしなくても大丈夫です）

## 手順（iPhoneだけでOK）

### 1. zipを展開する
ダウンロードしたzipを「ファイル」アプリでタップすると、`hachi-dungeon-web` フォルダができます。

### 2. GitHubのアカウントを作る（無料）
Safariで https://github.com を開き、「Sign up」から登録します。

### 3. 置き場所（リポジトリ）を作る
1. 右上の「＋」→「New repository」を選びます。
2. Repository name に `hachi-dungeon` と入力します。
3. **Public** を選びます（無料プランで公開するには Public が必要です）。
4. 「Create repository」を押します。

### 4. ファイルをアップロードする
1. 作成直後の画面にある **「uploading an existing file」** のリンクを押します。
   （見つからない場合は「Add file」→「Upload files」を選びます）
2. 「choose your files」から、`hachi-dungeon-web` フォルダの中の **6つのファイルをすべて選んで** アップロードします。
   ※ フォルダごとではなく、中のファイルを選んでください。
3. 下の「Commit changes」を押します。

### 5. 公開する（GitHub Pages）
1. リポジトリの「Settings」→ 左メニューの「Pages」を開きます。
2. 「Build and deployment」の Source を **Deploy from a branch** にします。
3. Branch を **main**、フォルダを **/(root)** にして「Save」を押します。
4. 1〜2分待つと、ページ上部に公開URLが表示されます。
   形式：`https://あなたのユーザー名.github.io/hachi-dungeon/`

### 6. ホーム画面に追加する
1. 公開URLをiPhoneの **Safari** で開きます。
2. 下の共有ボタン（□に↑）→「**ホーム画面に追加**」を選びます。

### 7. ホーム画面から1回起動する（大事）
ネットにつながった状態で、**ホーム画面のアイコンから1回起動**します。
タイトル画面に「**✓ オフライン準備OK**」と出れば完了です。

> ホーム画面のアプリはSafariとは別にデータを保存するので、この手順が必要です。

### 8. 機内モードで確認
機内モードにして、アイコンから起動して遊べたら成功です。

## うまくいかないとき
- **URLを開くと404になる**：公開まで数分かかることがあります。少し待ってから開き直してください。
- **「オフライン準備OK」が出ない**：ネットにつないだまま一度アプリを閉じ、もう一度起動してください。
- **縦画面になる**：iPhoneを横向きにしてください（画面の向きのロックを解除しておきます）。

## ゲームを更新したとき
`index.html` を新しいものに差し替えたら、`sw.js` の `hachi-dungeon-v1` を `v2` に変えて一緒にアップロードします。
そのあと、ネットにつないだ状態でアプリを2回ほど起動し直すと、新しい版になります。

## 遊び方
- ◀ ▶：移動
- ⚔ 攻撃：押しっぱなしで連続攻撃
- ▲ ジャンプ：長押しで高く跳びます
- ★ スキル：キャラごとの必殺技（使うとしばらく使えません）
- » 回避：一瞬無敵になってダッシュします
- 敵をすべて倒すと出口が開きます。3・6・9階はボス戦です。
